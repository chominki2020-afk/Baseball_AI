  • 내야 땅볼 방향 리그 평균 수준 (63% 당김) → 정상 수비
  • 외야 공중 타구 방향 고름 (29% 당김) → 정상
  • 투구와 연결 몸쪽 공 63% 당김 / 바깥쪽 32% → 당긴 쪽 수비면 몸쪽, 정상 수비면 바깥쪽으로
